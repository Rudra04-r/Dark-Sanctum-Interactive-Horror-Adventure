🕯️ Dark Sanctum

Interactive Horror Adventure Game
Dark Sanctum is an interactive horror game set in Ravenswood Asylum. Players make choices that shape the story, affect sanity, and lead to multiple endings. Built with HTML, CSS, and JavaScript, it blends atmosphere, branching paths, and immersive storytelling.

👻 About the Project

Dark Sanctum is inspired by classic horror stories and choice-driven narrative games. The goal was to create an immersive environment where players confront fear, explore a haunted asylum, and experience a story shaped entirely by their decisions.

🎮 Features

🏚️ Explore the eerie Ravenswood Asylum

🔀 Branching narrative with 20+ decision points

😵 Sanity system that influences outcomes

🔚 Multiple unique endings

🧩 Replayable with different story paths

🌑 Atmospheric visuals designed for horror immersion

🛠️ How It Works

Built using:

HTML — Scene structure

CSS — Horror-themed visual design

JavaScript — Game logic, branching choices, sanity tracking

Each scene contains text, images, and choices. Event listeners handle user decisions and move players through different narrative paths.
